# HH Vacancies Parser 🚀

Проект для сбора и анализа вакансий с платформы HeadHunter, их сохранения в PostgreSQL и предоставления удобного интерфейса для работы с данными.

## 📌 Возможности

- Парсинг данных о компаниях и вакансиях с API HeadHunter
- Сохранение данных в реляционную базу данных PostgreSQL
- Удобный интерфейс для анализа вакансий:
  - Получение списка компаний и количества вакансий
  - Поиск вакансий с зарплатой выше средней
  - Фильтрация по ключевым словам
- Поддержка обработки нестандартных символов в тексте
- Логирование всех операций

## 🛠 Технологический стек

- Python 3.10+
- PostgreSQL 14+
- Psycopg2 (для работы с PostgreSQL)
- Requests (для HTTP-запросов)
- Logging (для логирования операций)
